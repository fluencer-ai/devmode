## Residual risks (left open)

- **Codex fallback drift.** `codex_hooks.py` keeps a `_fallback_evaluate`
  with the v1 rules (including the split-flag gap of finding 1). It runs only
  when no `guardrails.py` is found; `install.sh` always copies one next to the
  Codex hook, so a normal install never reaches it. Worth deleting or
  delegating to the same rules in a later change.
- **Other delete commands.** `find ... -delete`, `git clean` without `-f`, and
  `rsync --delete` are out of R05's scope by design; the guard is a seatbelt,
  not a sandbox.
